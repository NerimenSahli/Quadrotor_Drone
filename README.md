🚁 SoC-Based Flight Controller for UAVsDesign and Implementation on Xilinx Zynq-7010
📖 Overview
This project involves the end-to-end development of a custom flight controller for a quadrotor drone using a Hardware/Software (HW/SW) co-design methodology. By utilizing the Zynq-7010 System-on-Chip (SoC), the system partitions time-critical tasks into FPGA logic to ensure microsecond-level determinism while leveraging the ARM processor for complex navigation and control algorithms.  The work spans the entire development cycle, from deriving non-linear equations of motion to physical flight testing.  🏗 System Architecture (HW/SW Partitioning)The architecture follows a strategic partitioning strategy to maximize reliability and performance:  🟦 Programmable Logic (PL - FPGA)Handled tasks requiring absolute temporal determinism to avoid mechanical instability:  AXI PWM Generation: Dedicated hardware IP cores for jitter-free motor control.  Sensor Interfacing: Hardware-level I2C management (MPU6050) to offload bit-level communication from the CPU.  Telemetry Buffer: A deep, BRAM-backed FIFO for the ESP-01S Wi-Fi module to prevent data loss during high CPU utilization.  🟩 Processing System (PS - ARM Cortex-A9)Responsible for high-level "intelligence" and control:  State Estimation: Implementation of a discrete-time Kalman Filter (100 Hz) to fuse accelerometer and gyroscope data for accurate Euler angles.  Control Logic: Execution of nested PID control laws for attitude and altitude stabilization.  Navigation: Processing pilot set-points and calculating error corrections.  🛠 Tech StackHardware: Zybo (Zynq-7000) Development Board, MPU6050 (IMU), HMC5883L (Magnetometer), ESP-01S (Wi-Fi), SimonK 30A ESCs.  Firmware: Embedded C/C++ (Vivado SDK).  Hardware Design: VHDL/Verilog (Vivado Design Suite).  Modeling & Simulation: MATLAB/Simulink (6-DOF Rigid Body Dynamics).  🚀 Key Implementation HighlightsHardware-in-the-Loop (HIL): Validated control gains by integrating the physical Zynq controller with a high-fidelity numerical plant model in Simulink.  Power Efficiency: The entire hardware peripheral subsystem draws less than 25 mW, proving the efficiency of FPGA offloading compared to software-driven approaches.  Deterministic Actuation: Achieved microsecond-level accuracy for PWM signals, ensuring stable propulsion regardless of software load.  📊 ResultsStability: Successfully achieved attitude stability and robustness against external disturbances during experimental flights.  Estimation: Validated the Kalman Filter’s ability to provide stable 100 Hz estimates by mitigating sensor noise and integration drift.  Payload: Designed to support a quadrotor with a total mass of 1.2 kg.
